-------------------------------------------------------------------------------------
| Elemento       | ¿Qué significa?                                                  |
| -------------- | ---------------------------------------------------------------- |
| `README.md`    | Archivo que explica cómo funciona un proyecto y cómo utilizarlo. |
| `# Título`     | Crea un encabezado principal.                                    |
| `## Subtítulo` | Crea un encabezado secundario.                                   |
| `- Elemento`   | Crea un elemento de una lista.                                   |
| `` `código` `` | Permite destacar un comando, archivo o fragmento de código.      |
| `[Texto](URL)` | Crea un enlace a una página web.                                 |
| ` ``` `        | Permite mostrar un bloque de código.                             |
