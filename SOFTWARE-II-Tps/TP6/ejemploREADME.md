# Servidor de Carteles ASCII

## 1. Descripción

Proyecto web desarrollado con Node.js, Express y Figlet que muestra tres carteles ASCII en el navegador: nuestro nombre, Software II y ¡Vamos 5to!

## 2. Requisitos

- Visual Studio Code.
- Node.js y npm.
- Un navegador web.

Descargas:
- [Visual Studio Code](https://code.visualstudio.com/)
- [Node.js](https://nodejs.org/)

## 3. Instalación

Crear una carpeta llamada `TP6-ejer18` y abrirla en VS Code.

Abrir la terminal y ejecutar:

```bash
npm init -y
npm install express figlet
```

## 4. Ejecución

Crear el archivo `app.js` con el código del servidor.

Ejecutar:

```bash
node app.js
```

Abrir el navegador e ingresar a:

http://localhost:3000

## 5. Resultado

El navegador mostrará los tres carteles ASCII generados con Figlet.

Para detener el servidor, presionar `Ctrl + C` en la terminal.

## 6. Estructura del proyecto

Al finalizar, la carpeta tendrá una estructura similar a esta:

```text
TP6-ejer8/
│
├── node_modules/
├── app.js
├── package.json
├── package-lock.json
└── README.md
```

Descripción de los archivos:

- `app.js`: contiene el código del servidor.
- `package.json`: contiene información y dependencias del proyecto.
- `package-lock.json`: registra las versiones concretas de las dependencias.
- `README.md`: explica cómo instalar, configurar y ejecutar el proyecto.
- `node_modules/`: contiene las bibliotecas instaladas por npm.
